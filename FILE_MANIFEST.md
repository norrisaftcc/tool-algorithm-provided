This repository contains **instructor-delivered materials** for the AlgoCratic Futures™ immersive learning experience. These assets are NOT housed in Canvas LMS—they are delivered:

- In-person (Day 1, presentations, ceremonies)
- Via social media / Discord / Slack

- As "discovered" artifacts (hidden files, easter eggs)

## FILE DESCRIPTIONS

### /day-one
Materials for the first day ritual. Sets tone, establishes the world, gets buy-in.

| File | Purpose | Delivery Method |
|------|---------|-----------------|
| `WELCOME_PACKET.md` | Overview of "employment" at AlgoCratic | Printed or screen-shared |
| `TERMS_OF_SERVICE.md` | The click-through agreement with hidden absurdities | Form/Survey |
| `NON_DISCLOSURE_NON_COMPETE.md` | "You shall not compete against your own best interests" | Signed document (theatrical) |
| `WELCOME_SURVEY.md` | Baseline assessment disguised as onboarding | Form with the ToS buried |
| `CLEARANCE_CARD_TEMPLATE.pdf` | Physical or digital "badge" - starts INFRARED | Printable template |

### /ceremonies
Ritualized moments that mark progression and reinforce the world.

| File | Purpose | When Used |
|------|---------|-----------|
| `SPRINT_KICKOFF_SCRIPT.md` | How to start each sprint in-character | Every 2 weeks |
| `SPRINT_RETRO_RITUAL.md` | Retrospective format with AlgoCratic framing | End of each sprint |
| `CLEARANCE_PROMOTION_CEREMONY.md` | Script for promoting students up the hierarchy | As earned |
| `FINAL_PRESENTATION_PROTOCOL.md` | The capstone presentation format (LinkedIn on last slide) | Week 12 |

### /progress-updates
Bi-weekly "Performance Trajectory Reports" - actually reflection exercises.

| File | Purpose |
|------|---------|
| `WEEK_XX_TRAJECTORY_REPORT.md` | Specific prompts for that point in semester |
| `TEMPLATE_trajectory_report.md` | Base template for creating new ones |

### /acp-entities
SCP-style "containment protocols" for patterns, antipatterns, and memetic hazards.

| Entity | Real Concept |
|--------|--------------|
| `ACP-001-TUTORIAL-HELL` | Getting stuck watching tutorials instead of building |
| `ACP-002-COPY-PASTE-SYNDROME` | Using code without understanding it |
| `ACP-003-INFINITE-REFACTOR` | Never shipping because it's never "good enough" |
| `ACP-004-PREMATURE-OPTIMIZATION` | Optimizing before you have working code |
| `ACP-005-SOCIAL-MEDIA-VORTEX` | Time theft via infinite scroll |
| `ACP-006-IMPOSTOR-PATTERN` | Impostor syndrome (reframed as manageable) |
| `ACP-007-SUNK-COST-ARCHITECTURE` | Refusing to abandon bad code because of time invested |

### /linkedin-optimization
Gamified LinkedIn profile building. Students need a "LinkedIn Optimization Score" for final clearance.

| File | Purpose |
|------|---------|
| `CLEARANCE_REQUIREMENTS.md` | What's required at each clearance level |
| `PROFILE_COMPLETION_TRACKER.md` | Checklist disguised as compliance form |
| `HEADLINE_GENERATOR.md` | Templates + examples (satirizing influencer speak) |
| `BUZZWORD_BINGO.md` | Gamified vocabulary building |
| `INFLUENCER_VOICE_EXAMPLES.md` | "What NOT to do" + "Actually effective" examples |

### /memes
Visual content for social media delivery. Bypasses conscious bandwidth limits.

| Directory | Purpose |
|-----------|---------|
| `/templates` | Base images for generating weekly content |
| `/weekly` | Pre-planned meme content tied to curriculum |
| `MEME_STYLE_GUIDE.md` | Maintaining visual consistency |

### /growth-tracker
The GitHub Action that measures learning velocity.

| File | Purpose |
|------|---------|
| `growth-tracker.yml` | GitHub Action configuration |
| `startup-growth-bot.js` | Calculation logic |
| `METRICS_TEMPLATE.md` | The auto-updating leaderboard format |

### /underground-drops
"Classified" materials that students might "discover" - reinforces the world while delivering real content.

### /social-posts
Templates for ongoing communication through Discord/Slack/etc.
